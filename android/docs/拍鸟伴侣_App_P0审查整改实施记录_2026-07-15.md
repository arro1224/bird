## 1. 本次已完成

### 1.1 P0-1 盒子端契约

- 将 `contracts/openapi/bird_box_v1.yaml` 从少量 draft 路径扩展为 App 当前实际使用的设备、批次、图片、分组、审阅、复制、任务、日志和事件路径。
- 完善 `contracts/events/job_event.schema.json`，新增 `device_event.schema.json`。
- 新增 App 契约自动检查与模拟盒子契约检查。
- 契约中明确 `xmp_enabled`、低置信度、批量标签增删、任务状态转移与终态删除。

### 1.2 P0-2 跨页数据与刷新

- 图库请求增加 generation 令牌，旧搜索/旧筛选返回不再覆盖新结果。
- 设备、分组、照片详情、任务列表和任务详情增加并发请求防重。
- 任务详情在 WebSocket 已连接时停止 4 秒轮询；事件不可用时才启用 HTTP 降级轮询。
- 设备状态也增加事件优先、HTTP 降级的 5 秒刷新。
- 离线同步不再将不支持重放的任务控制/复制记录误判为已成功并删除。

### 1.3 P0-3 特殊分析状态

- 图库占位、已有缩略图的卡片和照片详情均能明确显示“低置信度”。
- 识别面板补充需要人工复核的解释。
- 新增低置信度 Widget 测试。

### 1.4 P0-4 批量操作闭环

- 增加批量删除标签。
- 增加基于操作前状态的批量撤销，标签增删也可反向撤销。
- 批量结果显示成功数和失败数，失败项仍保留选中。
- 设置诊断页增加待同步操作列表、失败原因、重试次数和“立即重试全部”入口。
- 模拟盒子支持 `tags` 筛选、`add_tags` 与 `remove_tags`。

### 1.5 P0-5 复制确认

- 创建复制任务前强制重新估算。
- 二次校验目标盘是否在线、是否仍有足够容量。
- XMP 改为真实开关并传入盒子请求。
- 新增过期估算、目标离线和 XMP 参数测试。

### 1.6 P0-6 设置与诊断

- `SettingsCubit` 改为结构化 State，设置页接入真实 App 版本、盒子 API 版本、隐私说明、连接信息和加载状态。
- 新增实际图片磁盘缓存统计，清理后重新统计并广播图库刷新，不删除待同步人工操作。
- `EventClient` 保留当前连接状态，诊断页不再用 250ms 等待猜测状态。
- 诊断日志改为保存到系统下载目录；平台不提供下载目录时保存到 App 文档目录。
