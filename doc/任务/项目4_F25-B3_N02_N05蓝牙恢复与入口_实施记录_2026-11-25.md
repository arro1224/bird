## 结论与边界

B3 本地实现完成：独立保存已验证 BLE 提示；仅 STA 绑定、没有 AP 档案或内存候选时可有界扫描恢复；旧地址失效可替换，同地址暂态失败可有限重试；连接页当前业务卡提供“恢复蓝牙控制”“更改网络”直接入口，重新搜索保持可见。权限、未发现、连接失败、身份不符、取消及超时分别处理。

## 改动与恢复规则

| 场景 | 已实现行为 |
| --- | --- |
| 仅 STA 使用过的盒子冷启动 | BLE 提示存储独立于 AP 凭据；验证 Device Info、通知及网络状态后保存，STA 与直连均能积累提示 |
| 提示内容及存储 | 记录设备 ID、可失效的平台连接句柄、广播名和验证时间；生产使用既有 Keystore 通道的独立 `ble-peer-hint:v1` 命名空间，不保存 AP 口令、配对会话或令牌 |
| 旧版本兼容 | 先用已验证内存候选及独立提示；缺独立提示时兼容读取旧 AP 中的 BLE 提示，成功连接后写入独立存储。没有 AP 档案不再阻止扫描 |
| 无提示／提示失效 | 一次有界扫描，仅将带 BirdBox Service 的广播作为候选；名称、信号和旧句柄只作排序提示，最终仍核对目标 `device_id` |
| 同名或其他盒子 | 不因名称匹配接受身份；身份不符在接替设备或释放旧业务 AP 之前拒绝，不保存错误设备为目标提示；无提示扫描可以继续核对下一个候选 |
| 确有另一个已连接 BLE 设备 | 明确返回身份不符，保留原控制会话，不自动换盒子 |
| 地址与暂态失败 | 对 GATT 未就绪、GATT 操作／恢复失败、命令回包超时白名单进行有限恢复；旧提示失败后可使用同地址的新广播，不再强制地址必须变化 |
| 重试上限 | 默认总期限 30 秒（覆盖提示读取、扫描、GATT 和身份核验），扫描默认 10 秒，最多收集 16 个候选，总连接尝试最多 3 次，同一地址最多 2 次 |
| 权限／蓝牙关闭／定位关闭／安全拒绝 | 保留原分类，不因 `retryable=true` 对所有错误盲目重试；权限失败不触发额外连接重试或兜底扫描 |
| 连点和多调用 | 同目标合并为同一次恢复；不同目标返回忙。加入者取消只结束自己的等待，不取消原恢复 |
| 取消与迟到回复 | 取消使本次 BLE owner 失效，释放其控制资源，迟到 GATT／存储结果不能更新新会话；总期限超时与用户取消使用不同提示 |
| 业务卡入口 | 按当前业务设备 ID 进入已有网络设置；“恢复蓝牙控制”显式触发一次恢复，“更改网络”只进入设置；路由守卫合并连点 |
| 页面交接 | 进入设置前只停止发现扫描，不释放业务网络；恢复后由仓库／设置持有控制会话，发现页作为观察者返回；用户选择其他设备时重新取得明确所有权 |
| 设备切换及页面退出 | 取消旧设置页恢复并拒绝迟到结果；切换后旧页面禁用控制，不能向新盒子下发原设备操作 |

没有增加盒子网络接口、修改 RC4 冻结协议或放宽身份／通知／原生释放检查。未发现和恢复超时采用 App 内部异常，既有权限及 GATT 错误继续走原错误映射。
