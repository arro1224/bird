# 09-16 联调反馈：App 适配要求

## 结论

本次反馈分为两类：

1. BLE 搜索/配对：当前主要卡在 Android BLE Bond，后端 HTTP 接口尚未参与。
2. 复制功能：后端已有普通复制基础接口，但 App 尚未完成 RC3 任务闭环；不要只修改页面按钮或重复改造已可用的预检/创建流程。

后端已完成一轮整改：能力状态现在按真实存储返回；元数据更新和完整备份会明确返回不可用，不再返回空成功。App 必须按能力字段隐藏/置灰对应入口，不要为这两项编造成功页面。

## 一、BLE：必须先修复和回传

### 已确认现象

- OPPO 可以发现 `BirdBox-7A533A6F`。
- GATT 连接成功，设备信息读取成功。
- 点击“开始配对”后失败，诊断为 `ble_bond_timeout`，`bondState=not_bonded`，`operation=bond`。
- 失败发生在 Android Bond 阶段，尚未写入 `open_pairing`，因此不是后端 HTTP 接口返回的错误。
- 华为目前搜索不到盒子，暂不能仅凭现象判断是 App 还是板端广播问题。

### App 需要检查/修改

1. 点击“开始配对”时必须先调用 `createBond()`，等待 `BOND_BONDED` 后再写加密特征。
2. Bond 成功后应重新连接 GATT、重新发现服务、恢复通知订阅，再发送 `open_pairing`。
3. Bond 超时、用户拒绝或 GATT 5/12/15 时，保留首次根因，不要被后续断开事件覆盖。
4. 日志必须保留：手机型号、Android 版本、扫描诊断编号、GATT status、bondState、失败操作、特征 UUID。
5. 不要先修改 BLE UUID、验证码 `123456` 或后端地址；当前 OPPO 已证明 UUID、广播发现和设备信息读取链路可以走通。

### 与板端的配合点

App 提交 Bond 失败日志后，板端检查 BlueZ 是否收到配对请求、Agent 是否正常、是否出现安全协商错误。App 和板端日志需要使用同一时间点或扫描诊断编号关联。

华为问题需要同时提供：

- 手机型号、Android 版本、蓝牙及附近设备权限状态；
- App 扫描开始/结束及扫描回调日志；
- 板端广播包、广播服务 UUID、广播时长日志。

在证据齐全前，不要把华为问题归因到后端。

## 二、复制功能：App 当前需要补齐的范围

### 已有、不要重复改造

当前 App 已接入以下基础流程：

- 选择复制范围；
- 选择照片或筛选结果；
- 预检；
- 选择目标盘和冲突策略；
- 创建复制任务。

这些流程对应后端现有的四种普通复制范围：已选照片、筛选结果、已识别照片、整批照片。

### 尚未完成的 App 功能

如果产品仍要求完整 RC3，App 需要接入并展示：

- 复制任务列表和任务详情；
- 当前进度、事件、文件明细和报告；
- 暂停、继续、取消、失败重试；
- 安全移除目标盘；
- 元数据更新任务；
- 完整备份入口及结果；
- 创建任务成功后的任务中心跳转，而不是只关闭弹窗。

### 与后端的接口边界

| App 行为 | 后端要求 | 当前状态 |
|---|---|---|
| 读取复制能力 | 后端必须返回真实的 `supported_scopes`、存储状态和可用功能 | 已改为真实状态；App 只按返回值显示 |
| 创建普通复制任务 | 使用现有预检/创建接口 | 基础流程可用 |
| 查看任务进度/详情/事件/报告 | 后端先冻结 `copy_jobs_v1` 的路径和字段，App 按 OpenAPI 接入 | App 尚未接入完整闭环 |
| 暂停/继续/取消/失败重试 | 后端提供对应动作和幂等规则，App 不自行推断状态 | 双方均需补齐 |
| 元数据更新 | 后端能力为可用时才显示入口 | 当前返回 `metadata_export_ready=false`，App 必须隐藏或置灰 |
| 完整备份 | 后端能力为可用时才显示入口 | 当前预检返回 `COPY_SCOPE_UNSUPPORTED`，App 不得进入创建流程 |
| 安全移除 | 后端先提供目标盘安全移除接口及状态 | App 目前只有路由常量，未接入 |

App 不要自行猜测接口路径、状态值或报告结构。后端完成字段冻结并提供示例响应后，再进行页面接入。

### 后端本轮已冻结的负向行为

- `copy-capabilities` 不会把未插入源卡、不可写目标盘或存储协议不匹配报告为 `copy_ready=true`。
- `media_full_backup` 预检直接返回 `COPY_SCOPE_UNSUPPORTED`。
- 元数据更新相关调用返回 `METADATA_EXPORT_UNAVAILABLE`，不能按空任务成功处理。
- 预检明细 `/api/v1/copy-previews/{preview_id}/items` 返回实际计划文件，App 不应再把空列表当成正常结果。

## 三、App 本轮验收必须回传的内容

每个问题只回传有助于定位的内容：

1. 完整操作步骤：从哪个页面开始、点击顺序、失败时间。
2. App 诊断日志：扫描编号、手机型号、Android 版本、GATT status、bondState、操作名、特征 UUID。
3. 复制任务：请求/响应摘要、`job_id`、最终状态、失败项及错误码。
4. 只有界面显示异常时才附截图；只有时序或页面跳转无法用文字说明时才附录屏。

不要只回传“按钮已点击”“功能已完成”，也不要用截图替代协议日志。

## 四、App 侧验收标准

- OPPO：发现盒子、读取设备信息、Bond、发送 `open_pairing`、输入验证码并完成配对。
- 华为：至少回传可复现日志，明确是无广播、无扫描回调还是连接失败。
- 普通复制：创建任务后能进入任务详情，能看到真实状态、文件数和结果。
- 后端能力为不可用时，App 不显示“可用”入口，不把占位成功当作真实完成。
