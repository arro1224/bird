## 修改

- 新增只读 `ReusableBleSession` 能力，repository 提供当前实际连接的可信 BLE 设备、可观察 owner 及会话变化。初始化查找页优先观察现有 owner，不重新 claim，不取消已有 native preparation；观察者关闭不 end 现有 GATT。
- 当前 BLE 盒子以已读回且仍连接的 device info 为依据，独立于广告候选展示；已验证业务盒子以全局 `DeviceSessionState.isConnected` 为依据，分开说明 BLE 控制状态。扫描结束、无广播或列表为空不移除有效当前设备。
- 重扫只清本轮候选及扫描诊断，不清当前可信连接、不调用 reset/disconnect；返回查找也只在 repository 确认会话仍有效时保留。旧实现或不能确认有效性的状态继续使用原有释放门禁。
- 当前盒子使用已验证关联的 opaque transport ID 从候选区去重；候选按同一 ID 合并。广播名称、RSSI 及未验证 device info 不用于推断真实身份，换地址的候选仍须连接验证。
- 只有用户显式切换盒子、配对控制或取消才接管控制 owner。会话切换通知让旧页面转为观察新 owner，旧扫描、设置返回、连接结果及旧页面清理不能覆盖或拆掉新会话。
- 前后台只重启已经结束/暂停的扫描；保留系统权限 preflight，不在拒绝、错误或设置打开失败后自动重扫。等待旧订阅取消期间再次换 owner 时，旧回调不再调用 stopDiscovery。
- 历史卡片保留“最近使用 · 状态待确认”，只为有效业务会话显示“业务已验证”。新增复用、丢失、扫描开始的关联诊断，沿用现有去敏导出。
