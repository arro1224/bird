## 已实现行为

| 场景 | 行为 |
| --- | --- |
| 手机连接外部 Wi-Fi | 点击后立即进入可编辑表单，后台只读名称；读取结果带来源和时间，口令由用户填写 |
| 本机提供热点 | 独立“使用这台手机的热点”入口，明确选择 `this_phone_hotspot`；引导在系统热点设置中开启并填写名称、密码，不读取客户端名称代替热点名称 |
| 无可靠热点检测 | 不根据读不到名称、蜂窝标签或无客户端关联推断正在开热点；由用户确认网络类型 |
| 失效的客户端名称 | Android 仅在关联完成且网络 ID 有效时返回 SSID；未关联返回 `not_connected`，不能把残留 SSID 当作当前网络 |
| 权限与定位 | 入口及表单说明定位权限用途；拒绝／仅大致位置时一次按需请求，失败仍可手填或盒子扫描。系统定位关闭及无关联分别说明，不自动改网络类型 |
| 慢速读取与刷新 | 单次名称读取最长 8 秒；等待时可编辑。已编辑、已选扫描目标、本机热点或已有口令时不自动换名；新读到的名称可显式“使用此名称” |
| 刷新失败 | 显示失败原因，保留名称、口令及原名称参考的来源和时间；不会空字符串覆盖草稿 |
| 盒子保存配置 | 只展示既有身份核对快照中的保存标记／名称，明确是盒子记录，不作为手机当次读取或自动填表依据；不新增查询或写入 |
| 同页扫描 | 手填、扫描中、完整结果、空结果、失败及取消共用同一表单实例；显示信号、安全类型和 BSSID，不自动选择扫描结果 |
| 用户选择不同目标 | 比较 SSID、BSSID 和安全类型；同名不同 AP 也清旧口令。反复选择同一配置保留口令 |
| 用户修改配置 | 修改名称或安全类型清旧口令并移除扫描 BSSID，转为手动提交；开放网络提交不含口令，改回加密类型不会复用旧口令 |
| 隐藏及不支持的网络 | 手填可标隐藏；空扫描可重试或手填；不支持的安全类型显示原因且不能点选。仅支持扫描的盒子必须明确选结果后才能提交 |
| 重复点击与扫描取消 | 扫描单次执行；ACK 前取消先记用户意图，取得真实 operation ID 后才发送取消；迟到批次不能覆盖草稿或完成取消中的扫描 |
| 等待终态 | 扫描默认总期限 30 秒，覆盖 ACK、结果分批及取消终态等待；超时返回保留输入的失败状态，不虚称板端已取消，允许重试 |
| 页面或目标改变 | 手机读取完成前核对页面、Cubit、设备及当前阶段；退出后不重新打开表单或申请权限；重新进入可开始新读取 |
| 最终确认及二维码 | 扫描中禁用加入按钮；只在最终表单确认时发送一次 STA 配置并清口令。二维码保留原路径和单次打开／确认，并核对返回时目标和阶段 |

手机读取结果和表单草稿仅在当前页面内存中持有；用户确认后沿用既有入网通道提交配置，本批未增加名称／口令的持久化或诊断输出。手机读取失败与盒子扫描失败分别表达；扫描超时没有改变底层 RC4 权威终态和请求关联规则。
