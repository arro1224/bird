## 5. 联调材料（回传联调 01 §三；mock 阶段，来自 mock 服务器/仓库冻结测试）

**请求/响应摘要（birdbox-copy-v1 RC3 全链路）：**

| 步骤 | 请求 | 响应要点 |
|---|---|---|
| 能力 | GET `/api/v1/copy-capabilities` | `revision=1.0-rc3, copy_ready=true, supported_scopes=[selected_assets, filtered_assets, recognized_assets, batch_all_assets, media_full_backup]` |
| 预检（负向） | POST `/api/v1/copy-jobs/preview`，`scope=media_full_backup` | **422** `{"error":{"code":"COPY_SCOPE_UNSUPPORTED"}}`（错误包络 §13.1） |
| 预检 | POST preview，`scope=kept_assets` | `preview_token`、`logical_photo_count=34`、`actual_file_count=67`、`conflict_count=3` |
| 预检明细 | GET `/api/v1/copy-previews/{id}/items?cursor=` | 20/页，冲突项 `conflict_decision=skip` |
| 创建 | POST `/api/v1/copy-jobs`（带 preview_token + X-Idempotency-Key） | 202 `{copy_job_id: copy_job_*, state: queued, event_seq: 1}` |
| 详情轮询 | GET `/api/v1/copy-jobs/{id}` | queued→acquiring_target(1.2s)→running→completed_with_errors(约 6.4s)；`state_version` 每转移 +1；`allowed_actions` 随状态变化 |
| 失败项 | GET `…/items?state=failed` | 1 项，`COPY_HASH_MISMATCH` 语义 |
| 事件 | GET `…/events?after_seq=N` | seq 严格递增，含 `item_failed` |
| 报告 | GET `…/report` | 非终态 409 COPY_REPORT_NOT_READY；终态 `failed_files=1`（部分成功） |
| 动作 | POST `…/actions/{pause,resume,cancel,retry_failed}`，body `{expected_state_version, reason:user_requested}` | 版本不符 **409 COPY_STATE_VERSION_CONFLICT**；pause→paused→resume 全链可用 |
| 安全移除 | POST `/api/v1/storage/devices/{media_id}/safe-remove`，body `{role, expected_copy_job_id}` | 任务占用 `{safe_to_remove:false, reason}`；空闲 `{safe_to_remove:true, keep_until:+60s}` |

**样本 job_id / 最终状态 / 失败项：** `copy_job_<ms>`；`completed_with_errors`；失败 1 项（`copy_item_0002`，DSC05002.JPG，COPY_HASH_MISMATCH），重试后可再次闭环。
