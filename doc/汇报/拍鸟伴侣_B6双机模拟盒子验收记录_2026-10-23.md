## 3. 发现与修复

### App 补修

旧模拟器缺少复制配置接口时，复制页收到通用 404，却显示“照片详情不可用 / 照片可能已被删除”。这是复制页上下文错误，不能据此判断照片被删。

- `UserMessageMapper.fromCopyConfigurationError` 将复制配置中的通用 404 改为“复制资源暂不可用”，引导重新检测和检查盒子服务。
- 专用 `COPY_*` 业务错误继续使用原有映射；没有把普通 404 猜成拔盘。
- 复制配置页采用此映射；获取预检和创建仍受原完整性门禁约束。
- 新增 widget 回归验证文案、禁止继续及零创建；另验证 `COPY_PREVIEW_EXPIRED` 等专用错误不被覆盖。相关文件共 14 项测试通过。
- 原有 31 个文件仅格式化，清单沿用 `build/b6/format-baseline-files.json`；最终 lib/test/tool 共 559 个 Dart 文件格式检查通过。

### 独立模拟盒子补修

源码位于 `D:/Androidstudio2/project/模拟盒子`，修改的是用户指定 APK 所属的独立模拟应用，不是 Python 后端。

1. 补齐实际返回 404 的 `/api/v1/storage/source`、`/api/v1/copy-preferences`、`/api/v1/copy-scope-options`；偏好支持版本冲突检查和重启持久化。
2. 预检明细增加显式 `plan_state`，按冲突策略设置复制/跳过，统一文件字节数，使全部分页与汇总对账。
3. 创建任务保留完整预检计划，移除“无论预检多少文件都换成固定两个演示文件”的旧行为。
4. 任务统计纳入跳过项，预检、任务与终态报告按同一批文件统计；终态耗时冻结。
5. 修复模拟推进器把后续文件提前并行启动的问题，使串行任务能观察中间进度及操作暂停/继续。
6. 扩展 `tests/server_contract_test.dart`；新增 `tests/normal_app_copy_contract_check.dart`，直接使用项目 4 当前生产 API 解析器、仓库及完整计划校验器验证三种冲突策略、全部分页、任务冻结和终态报告。

这里的源绑定 token、只读声明、存储容量、范围数量及复制动作都是合成夹具。不能据此证明真实卡只读、token 签发/轮转、筛选匹配集合、真实写盘或重名文件后缀正确。
