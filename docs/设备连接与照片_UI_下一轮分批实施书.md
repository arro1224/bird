## 2. 统一产品原则

1. 页面默认只展示与当前操作直接相关的信息；设备健康、温度正常、存储正常等不常驻展示。
2. 连接中断、温度达到硬件临界值、存储卡不可用、任务失败才显示顶部异常提示，并给出可执行动作。
3. 照片分析期间允许浏览已加载或已缓存图片；修改识别、批量标记、重新处理等写操作是否禁用，必须由硬件端状态契约决定。
4. P0 不展示复制到 NAS 的入口、状态或承诺。后续作为独立功能重新评审。
5. 不使用设计样图、网络鸟图或写死算法结果充当真实设备业务数据。
6. 界面优先描述“用户正在做什么、结果怎样、下一步怎么办”，不直接展示算法名、协议名、文件格式名和内部状态名。

## 4. 批次 0 排查清单

1. 使用 `flutter run --flavor bird -t lib/main_bird.dart -d <device>` 获取启动期 Dart 日志；不要只安装历史 APK。
2. 清空本次应用 logcat 后冷启动，保存 `E/AndroidRuntime`、`E/flutter`、`Dart` 和 `ActivityTaskManager` 日志。
3. 核对 APK 的构建时间、版本号、ABI 与安装包；确认安装的是 `app-bird-debug.apk`。
4. 若仅 Android 8.1 黑屏，建立最小启动页验证，逐步恢复插件与启动初始化；不要先改 UI 掩盖启动问题。

## 5. 硬件端需确认的契约

| 议题 | 最小字段/接口 | App 行为 |
|---|---|---|
| 分析期间访问 | `processingState`、`browseAllowed`、`writeAllowed`、`blockedReason` | 浏览照常；写操作按权限禁用。 |
| 增量扫描 | 文件稳定 ID、`modifiedAt`/size/hash、`analysisVersion`、扫描进度 | 保留旧列表，增量刷新新增与变更项。 |
| 异常阈值 | 温度告警/恢复阈值、存储告警阈值、错误码与建议动作 | 只在异常时显示顶部条，使用硬件真实文案或错误码映射。 |
| 离线能力 | 批次、分页、详情快照版本和有效期 | 仅承诺已缓存数据可浏览，不承诺完整离线相册。 |
