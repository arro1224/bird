# 拍鸟伴侣任务与“我的/设备”模块功能表

## 1. 文档说明

本文档整理当前独立前端项目中已经完成的“任务”和“我的/设备”两个模块，说明各功能的页面实现、数据来源、完成状态及后续接入要求。

当前项目定位为设计稿还原和前端交互演示。设备连接首页已经部分复用原项目的真实会话状态，任务业务、设置保存、设备详情等功能仍以演示数据或本地状态为主。

### 1.1 状态定义

| 状态 | 含义 |
|---|---|
| 已完成 | 页面与前端交互已经实现，可稳定演示 |
| 演示完成 | 页面和流程已经实现，但使用前端演示数据 |
| 部分接入 | 已接入原项目的部分真实状态或服务，仍包含演示数据 |
| 待接入 | 页面已存在，等待连接后端接口、设备服务或本地持久化 |
| 待完善 | 当前仍有占位页面、无效入口或交互缺口 |

## 6. 已确认的问题

1. 任务导航仍包含 `demo-*` 固定任务 ID，不能直接用于真实任务 ID。
2. 任务暂停、继续、取消、重试等操作目前只修改前端状态。
3. 设备首页使用真实状态，但设备详情仍显示固定演示数据。
4. 设备详情中的重新连接按钮目前只显示提示。
5. 断开连接后，任务控制按钮仍然可以修改本地任务状态。
6. 相册入口仍为占位页面，任务到审阅、相册的完整流程尚未完成。
7. 设备重新搜索开始后不会自动恢复到空闲状态。
8. 默认筛选条件、命名与目录规则等入口暂时没有交互。
9. 设置值尚未持久化，应用重启后会恢复默认值。

## 7. 后续开发优先级

### P0：真实业务链路

1. 移除任务页面中的固定演示任务 ID。
2. 使用 `JobRepository` 加载任务列表、详情和实时进度。
3. 将暂停、继续、取消、重试、跳过失败项连接到任务控制接口。
4. 使用 `BatchRepository` 接入存储卡扫描、批次创建和当前批次。
5. 使用 `CopyRepository` 接入复制预估、目标存储和复制任务创建。
6. 统一设备首页与设备详情的数据来源。
7. 断开连接时禁止发送会造成错误反馈的任务操作。

### P1：完整页面流程

1. 将当前批次和任务结果正确连接到相册模块。
2. 将 AI 分析完成后的流程连接到真实批次审阅页面。
3. 完成设备搜索的加载、成功、失败和超时状态。
4. 完成默认筛选条件和命名目录规则页面。
5. 接入日志和诊断包真实导出。

### P2：设置与体验完善

1. 为设置控制器增加持久化存储。
2. 增加设置读取失败、保存失败和恢复默认状态。
3. 完善离线状态、空状态和接口异常提示。
4. 完成真实设备上的关键业务流程测试。
