# B0｜birdbox-v1 接口冻结门禁

本批次以《任务模块接口冻结与新增接口评估说明书（2026-08-06）》为实施基线。

## 结论

- 现有契约：`birdbox-v1@1.0.0`，保持不变。
- 新增接口：0 个。
- B0 范围：冻结 OpenAPI、JSON Schema、原接口说明与 ADR，并建立自动回归校验。
- App 侧差异必须通过兼容解析、请求校验或页面实现解决，不得反向修改 v1。

## 自动门禁

执行：

```powershell
dart run tool/contracts/verify_contracts.dart
flutter test test/contracts/contract_validation_test.dart
```

门禁会校验：

1. 冻结文件的 SHA-256 与 `birdbox-v1-freeze.json` 完全一致。
2. OpenAPI 的路径与 HTTP 方法集合完全等于已冻结集合。
3. 所有 `$ref`、Schema 与正反 fixture 保持一致。
4. App 的 `/api/v1` 路径只在 `ApiEndpoints` 中集中声明，并与 OpenAPI 路径集合一致。
5. 所有 POST 继续使用 `X-Idempotency-Key`，所有路径继续要求 `X-Api-Version: v1`。

`--strict-baseline` 仍要求真实盒子、固件、部署、数据库与责任人资料齐全；这些外部资料未补齐时，B0 的客户端冻结门禁可以通过，但不能宣称真实盒子基线闭环。

## 新接口提案规则

若后续产品能力无法由 v1 表达，必须先复制 `proposals/TEMPLATE.md` 建立独立、版本化提案。提案获批前：

- 不得编辑 v1 OpenAPI、Schema、原接口说明或 ADR；
- 不得在 App 或 mock 中添加未声明路径、参数、字段、状态码；
- 不得用“可选字段”“临时参数”或修改旧语义绕过冻结门禁。
