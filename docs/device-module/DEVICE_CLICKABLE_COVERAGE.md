- 重新连接：进入冻结稿 01/02 流程。

- 网络帮助：进入冻结稿 13。
- 切换网络：进入冻结稿 01/02。
- 导出网络诊断：进入冻结稿 12。

- 当前工作、相册 Tab、任务 Tab：只调用现有跨模块路由，不属于本轮视觉开发。

## 验收标准

1. 首页 9 个设备入口都能进入对应页面。
2. 设备模块内所有箭头行、按钮、图标按钮都有可观察结果。
3. 不再用 Snackbar 代替应有的详情页、底部面板或表单页。
4. 所有新增页面支持返回，底部面板支持关闭或下滑退出。
5. 异步操作显示 150-300ms 内可见的加载反馈，执行期间禁用重复点击。
6. 点击目标不小于 48dp，文字放大后不遮挡、不越界。
7. 设备模块测试逐入口覆盖，并在模拟器逐项点击验收。

- 当前模拟器未连接真实拍鸟盒子，因此设备状态、网络诊断和日志导出显示断开态或演示占位数据；真实数据仍由已有仓储和设备会话接口提供。
- 问题反馈目前保存为前端演示提示，待后端反馈接口接入后替换提交实现。
- `mobile_scanner` 仍会产生 Flutter 关于 Kotlin Gradle Plugin 的升级提示，但当前 `birdV1` APK 已成功构建，不属于本轮设备 UI 阻塞问题。
