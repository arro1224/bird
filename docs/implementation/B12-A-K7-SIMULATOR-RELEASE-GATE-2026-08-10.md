# B12-A：K7 模拟盒子发布前门禁

日期：2026-08-10  
前置批次：B11 任务设计收口与生产可达性  
测试对象：已启动的 K7 模拟盒子与 3,672 张确定性模拟数据集  
结论：**B12-A 模拟盒子门禁通过；B12-B 真实硬件门禁仍未完成，当前结论不能替代正式发布批准。**

## 1. 范围与边界

当前没有真实盒子，因此 B12 拆分为：

- **B12-A**：验证冻结协议、生产 API 适配、任务写入状态、照片搜索筛选、分页、媒体、报告、日志、全量自动化和 Android 构建；
- **B12-B**：后续使用真实盒子、真实 SD 卡、真实目标盘和 Android 设备完成硬件、局域网、性能与手工视觉验收。

B12-A 不把以下模拟结果声明为真机结论：SD 卡物理拔插、损坏卡、USB 目标盘拔出、真实磁盘空间、低电量、过温、真实 Wi-Fi 断线/重连、3,672+ 实拍数据的盒子端吞吐、Android 设备内手工点击和截图。

## 3. B12-A 新增门禁

新增 `tool/acceptance/b12a_k7_acceptance.dart`，可直接连接已经启动的 K7 模拟盒子：

```powershell
dart run tool/acceptance/b12a_k7_acceptance.dart --base-url=http://127.0.0.1:8787
```

门禁覆盖：

- 健康状态、设备 ID、API 版本、当前项目和存储卡扫描一致性；
- 场景与缩略图读取；
- “白鹭”和“普通翠鸟”搜索；
- 白鹭 + 评分 + 识别度 + 标签 + 清晰度 + 识别状态组合筛选；
- 完整候选集扫描和进度完成事件；
- 在线/离线复制目标；
- 导入、AI 分析、复制和重扫四类任务写入；
- 暂停、恢复、取消、过期版本 409、不可用动作 422；
- 取消后的权威复制报告；
- 诊断日志签名地址和非空下载。

新增的自动化用例以 3,672 张确定性模拟照片运行同一门禁，服务端扫描页大小为 200，因此“白鹭”搜索会实际跨越 19 个服务端分页。
