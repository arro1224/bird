## 1. 本批次目标

1. 在“加入现有 Wi-Fi”页面提供冻结顺序的三条入口：
   - 使用手机安全共享 Wi-Fi（DPP，条件满足时推荐）；
   - 扫描 Wi-Fi 二维码；
   - 选择或手动输入网络。
2. DPP 入口在展示前同时检查 Android 手机、系统 Activity、盒子能力和当前授权会话。
3. 增加标准 `WIFI:` 二维码的严格本地解析、确认与 `wifi_qr` 提交链路。
4. 密码、二维码原文、完整 BSSID 和 DPP URI 不进入 Bloc 状态、普通页面文案、日志或业务后端。
5. DPP 不可用或失败时保留二维码和普通 BLE 凭据兜底，不自动跳转密码输入框。

## 2. 实施结果

### 2.1 DPP 五项条件合并门控

新增不含秘密的 `DppAvailability`，由生产 `ProvisioningRepositoryImpl` 合并以下条件：

1. Android API 能力满足 Easy Connect 要求；
2. `WifiManager.isEasyConnectSupported()` 对应平台结果为 true；
3. 系统存在可处理 Easy Connect 的 Activity；
4. 盒子 `dpp_enrollee_supported=true` 且 AKM 至少含 `psk` 或 `sae`；
5. BLE 已取得 Device Info、必需通知已订阅且存在有效配对会话或 Bearer Token。

任何能力查询异常均 fail-closed，DPP 卡片保持禁用并显示“当前手机或盒子暂不支持安全共享”。命令点击时生产 Repository 仍会再次检查手机与盒子能力，避免展示后能力变化导致越权启动。

### 2.2 加入现有 Wi-Fi 页面

页面固定顺序调整为：

1. `使用手机安全共享 Wi-Fi`：仅合并能力为 true 时可点击并展示“推荐”；
2. `扫描 Wi-Fi 二维码`：本地扫码入口；
3. `选择或手动输入网络`：打开底部选择器，继续使用现有盒子扫描或手动输入流程。

DPP 失败页提供：重新尝试安全共享、扫描 Wi-Fi 二维码、选择或手动输入网络、返回盒子直连。失败不会自动打开密码表单。

### 2.3 Wi-Fi 二维码解析

新增严格 `WIFI:` 解析器，支持：

- `nopass`、WPA/WPA2、WPA3/SAE、WPA2/WPA3 transition；
- `S`、`P`、`T`、`H`、`B` 标准字段；
- 分号、冒号、逗号、双引号和反斜杠转义；
- 隐藏网络；
- 可选标准 BSSID。

解析器拒绝：

- 非 `WIFI:` 或缺失终止符的内容；
- WEP、企业网和未知安全类型；
- 重复字段、未知字段和非法转义；
- 空或超过 32 字节的 SSID；
- 过短/过长密码、开放网络携带密码；
- 非法 BSSID 和控制字符。

### 2.4 扫码与安全确认

新增专用 Wi-Fi 二维码扫描页：

- 只扫描二维码格式；
- 无效内容显示通用错误，不回显原文；
- 确认页只展示 SSID、安全类型、隐藏网络和“是否包含接入点标识”；
- 不展示密码或完整 BSSID；
- 相机权限失败可进入系统设置；
- 取消、重新扫描或页面销毁时清除页面持有的候选凭据引用。

### 2.5 冻结协议提交

二维码确认后转换为现有 `StaNetworkConfiguration`：

- `target_mode=infrastructure_sta`；
- `provisioning_method=wifi_qr`；
- 含 BSSID 时使用 `selection_method=scan_result`；
- 不含 BSSID 时使用 `selection_method=manual` 且 `bssid=null`。

没有新增 BLE 命令、业务 API 或后端密码接口。

### 2.6 生产门禁

生产完整性门禁新增检查：

- 生产 Repository 必须实现 DPP 合并能力查询；
- 合并查询必须调用 Android 平台能力；
- 三条冻结入口文案必须存在；
- Wi-Fi 二维码入口必须打开专用扫描页；
- 严格二维码解析器必须存在。

## 6. 真实设备验收清单

1. Android API 28、API 29+ 但 Easy Connect=false、API 29+ 且 Easy Connect=true 各一台。
2. 验证盒子 DPP=false 时卡片禁用，二维码和普通路径仍可完成。
3. 扫描 Android/iOS/路由器生成的 WPA2、WPA3、transition、开放网络二维码。
4. 验证包含转义 SSID、隐藏网络和 BSSID 的二维码。
5. 相机拒绝、永久拒绝、扫码取消、无效二维码和重新扫描。
6. 用日志和抓包确认二维码原文、外部 Wi-Fi 密码、完整 BSSID 不进入业务 API 和普通日志。
7. K7 DPP=true 前完成 Easy Connect Activity 成功、失败、取消、超时和 Activity 不存在场景。
8. DPP 成功后继续等待 `sta_connected` 与 `/health.device_id` 校验，不把 Android `RESULT_OK` 当成最终成功。
