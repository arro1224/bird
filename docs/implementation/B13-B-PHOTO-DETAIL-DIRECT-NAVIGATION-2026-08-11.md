# B13-B：照片详情左右快捷翻页

日期：2026-08-11  
前置批次：B13-A 照片详情识别度百分比统一

## 1. 交付结论

- 照片预览左右两侧增加深灰色上一张、下一张箭头，颜色使用现有 `AppColors.inkMuted`（`#706D68`）。
- 箭头使用 40dp 图标和 52×52dp 点击区域，并提供“上一张”“下一张”辅助提示。
- 第一张只显示下一张，中间照片同时显示两个箭头，最后一张只显示上一张，单张照片不显示箭头。
- 已加载序列末尾仍有后续分页时继续显示下一张箭头；点击后调用既有分页加载器并打开首个新增照片。
- 保存、详情加载或下一分页加载期间，箭头保持可见但禁用点击，避免重复触发。
- 右上角扩展菜单继续保留；菜单和照片箭头共用 `_goPrevious`、`_goNext`，不存在两套翻页逻辑。
- 翻页继续复用既有原地详情加载和审核断点保存能力。
- 外部接口新增 0 个、修改 0 个；照片模型和分页协议不变。
