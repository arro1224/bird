## 实施顺序

| 批次 | 实施内容 | 完成条件 |
| --- | --- | --- |
| B0 | 固定对照截图与项目基线 | 明确当前代码、对照包、设备密度和测试基线 |
| B1 | 压缩相册顶部布局 | 批次与记录入口同行，快捷筛选与高级筛选可达 |
| B2 | 把盒子状态移到标题栏 | 状态独占行撤下，盒子连接、电量及弹层可用 |
| B3 | 整理读取、缓存与异常提示 | 同一原因只提示一次，重连、刷新、取消筛选和处理冲突仍能执行 |
| B4 | 模拟盒子集成回归 | 四张场景截图、首屏测量及相关回归通过 |
| B5 | 真实 K7 联调 | 真实断线、接回、缓存和设备状态验证完成 |

### B0 固定对照组

1. 记录开始实施时的提交、工作区、Flutter SDK、构建身份及模拟器配置。方案核对时的提交为 `2b2e0f8b4`。实施前重新取实际值，并将已有本地修改与本轮改动区分开。
2. 保存 APK 原版的无筛选、筛选生效、设备弹层截图。记录初始筛选、批次、图卡上缘及首屏完整行数。对照截图按同一显示参数复现。
3. 运行相册、设备状态和照片详情的相关现有测试。先记录现有失败，再判断后续变化是否引入回归。核对从任务完成进入相册的定向跳转以及从拍摄记录进入历史批次的路径。

### B1 压缩首屏顶部

主要文件为 [gallery_page.dart](../../lib/bird_companion/features/gallery/presentation/gallery_page.dart)、[album_history_entry.dart](../../lib/bird_companion/features/gallery/presentation/widgets/album_history_entry.dart) 和 [active_filter_summary.dart](../../lib/bird_companion/features/gallery/presentation/widgets/active_filter_summary.dart)。

1. 调整相册首页的 `_GalleryHeader` 和 `_AlbumBatchHeading`，把批次日期与名称、文本版拍摄记录入口置于同一行，收紧各区块的垂直间距。长批次名称可截断，入口保持可点。标题栏时钟和批次同行入口均沿用同一拍摄记录路由，空相册的记录入口继续使用现有路径。
2. 保持「全部、待确认、已保留、已弃选、精选」的现有查询行为。高级筛选按钮固定在快捷项行右侧，快捷项在空间不足时可横滑。应用筛选后，用一行摘要显示当前条件，并保留展开和清除动作。清除沿用现有重置行为，更新网格与复制所用范围。
3. 保持现有照片网格规格、滚动位置、多选模式和分页触发点。历史批次也复用 `GalleryPage`，所以紧凑布局以 `rootMode` 区分。不要用缩小图卡取得首屏指标。

完成条件是两个拍摄记录入口都能打开同一页面，返回后位置可恢复。320dp 窄屏及 Android 放大字号下，主要动作能触达且布局无溢出，较长批次名称符合预期。相关测试更新为验证入口、路由与布局行为，对旧垂直间距的断言随设计更新。

### B2 合并 Wi-Fi 和电量展示

主要文件为 [gallery_page.dart](../../lib/bird_companion/features/gallery/presentation/gallery_page.dart)、[device_status_pills.dart](../../lib/bird_companion/features/device/presentation/widgets/device_status_pills.dart) 和 [device_status_sheet.dart](../../lib/bird_companion/features/device/presentation/widgets/device_status_sheet.dart)。

1. 在相册浏览态标题栏提供一个可点击的盒子状态入口，显示连接图标和电量百分比。连接状态读取 `DeviceSessionCubit`，电量读取现有 `DeviceStatusCubit`。保留现有状态加载和订阅路径，避免因入口移位增加请求或轮询。
2. 点击复用现有状态弹层及设备详情、重连等动作。存储容量、外接电源、盒子温度和 SD 卡信息在弹层里展示。确认弹层关闭和跳转经过原有导航层级。
3. 状态读取中、电量未知、正在恢复连接、已断开各有可区分的显示。一次状态读取失败按现有会话规则处理。找不到当次有效电量时显示未知，盒子已断开时不展示上次电量为当前值。
4. 状态入口至少保留 48dp 点击区域与完整的读屏名称。极窄或大字号下优先保留状态与拍摄记录，可将复制入口放入更多操作。多选时沿用现有选择计数和退出动作。

完成条件是正常态省去旧设备状态整行。状态入口在在线、读取中、恢复中和断开时表现符合上面的规则，已有详情和重连入口能完成跳转。

### B3 精简重复提示

主要文件为 [gallery_page.dart](../../lib/bird_companion/features/gallery/presentation/gallery_page.dart) 和 [gallery_candidate_notice.dart](../../lib/bird_companion/features/gallery/presentation/widgets/gallery_candidate_notice.dart)。继续消费现有查询、缓存、待同步和冲突状态。

| 场景 | 页面行为 |
| --- | --- |
| 首次读取且还没有照片 | 内容区显示一处加载提示。进入可取消的扫描后，同一提示提供取消动作 |
| 已经有照片，正在重新筛选 | 保留当前网格，显示一处可取消的筛选进度。取消后准确标记结果是否完整 |
| 离线且有缓存照片 | 合并相册顶部及底部重复提示。用一条说明交代当前为手机缓存，并提供「重新连接」。缓存只覆盖部分结果时标明范围，已触发重连时显示恢复中 |
| 离线且没有可浏览缓存 | 显示空态及重连动作 |
| 在线但筛选未完成或结果不完整 | 显示有明确动作的短提示，提供重新筛选或刷新。结果不完整时沿用现有复制禁用条件 |
| 待同步、照片修改冲突或设备异常 | 普通同步状态紧凑展示。冲突保留「处理冲突照片」入口。高温、SD 卡不可用和影响操作的异常保留明确提醒 |

同一断连原因在提示区只出现一次。连接图标作为状态标记留在标题栏。多个问题同时出现时，优先展示需要马上处理的提醒，其余有独立行动的项仍须可达。例如冲突出现时仍可从状态入口重连。核对从断线到重连的过渡，恢复后应自动撤下已失效的提示，并保留当前浏览与筛选状态。

相关现有回归分组：

- 布局与入口使用 `album_history_entry_test.dart`、`active_filter_summary_test.dart`、`gallery_selection_visibility_test.dart`。
- 查询与恢复使用 `b10_photo_filter_experience_test.dart`、`gallery_candidate_notice_test.dart`、`gallery_resilience_test.dart`。
- 设备及相邻页面使用 `device_status_pills_test.dart`、`device_status_cubit_test.dart`、`photo_detail_navigation_test.dart`、`analysis_to_album_materialization_test.dart`。

每批分别留存相关检查结果。B4 汇总受改模块的静态分析、测试结果、同尺寸改版前后截图和首屏测量。需要交付本地联调包时，使用项目 [构建说明](../../README.md) 里的正式 App Debug 流程，并记录包名、版本及提交。
