## 3. 放行条件

BLE RC4 专用校验器只有在以下条件同时满足时才返回通过：

1. 冻结基线状态为 `ready`，无未解决外部输入，固件 SHA 完整；
2. Git 工作树干净，App SHA 与当前提交一致；
3. `app-bird-release.apk` 存在，APK SHA-256 与证据一致；
4. 构建为 release、签名及验签均已确认，证书 SHA-256 与批准指纹一致；
5. 使用物理 Android 和真实路由器、盒子，不接受 emulator/SIM/mock；
6. K7-01～K7-10 恰好各出现一次且全部 passed，并引用存在的证据文件；
7. 盒子固件 SHA 与冻结基线一致，协议版本为 v1；
8. 脱敏复核、协议批准、QA/发布批准均完成；
9. JSON 和文本证据不含密码、口令、配对码/会话、Token、完整 DPP URI 或完整 MAC。

任一条件失败时输出 `releasable=false`、`real_k7_status=pending`，进程退出码为 2。B7 总门禁只有在专用校验步骤成功后才设置内部 `bleRc4Verified=true`；最终 verified 分支同时要求 Release 总流程状态为 passed。
