# 2026-10-04 App 与 Python 后端适配

## 本次修改

- 增加逐照片识别结果、事件补取与智能复制入口，支持识别开始前或中途开启。
- 显示识别、合格、排队、子任务及复制数量，复用 RC3 复制任务详情。
- 对齐后端 RC3 字段、任务路由与媒体 Bearer 鉴权。
- BLE 诊断导出提供简短摘要和编号分段，每段不超过 4096 UTF-8 字节，避免手机粘贴截断；提供完整快照 SHA-256。
- 配对失败后可以继续重试，保持既有蓝牙修复，不把本地模拟连接当作实机验证。

## 验证边界

已完成 Flutter 检查、测试 APK 构建及 Android 模拟器连接 Python 后端的实际操作。14 张识别结果生成 3 个固定复制子任务（6/6/2），目标文件数量和 SHA-256 与源文件一致。

本轮全量 App 测试为 767 项通过、1 项失败：历史交付证据 `outputs/RC4-HF-BLE-05/handoff-manifest.json` 缺失。该失败未伪造或跳过，不能写成全量通过。Native 蓝牙策略独立 JUnit 测试 20 项通过；不等于真实 OPPO/华为/K7 已通过。

真实蓝牙、实际板端算法、SD/USB 拔盘恢复和性能仍需实机验证。正式入口为 `lib/main_bird.dart`；`lib/main_bird_simulated.dart` 仅供本地调试，其模拟连接后的业务请求仍发送给 Python 后端。

## 后端要求

后端使用现有 `/api/v1`、鉴权和 RC3 协议，并需明确开启增量识别及智能跟随能力。App 根据能力和允许操作展示入口；健康接口可访问不代表真实 Pipeline 或复制已验收。
