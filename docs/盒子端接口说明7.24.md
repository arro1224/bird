# 盒子端接口说明

本文档根据当前 App 代码整理，用于手机端与拍鸟盒子端联调。

## 1. 通信概览

| 类型 | 地址/协议 | 功能 |
| --- | --- | --- |
| HTTP | `http(s)://{box-host}/api/v1` | 查询设备、照片、任务及提交操作 |
| WebSocket | `ws(s)://{box-host}/api/v1/events` | 实时推送设备和任务状态 |
| mDNS | `_birdbox._tcp.local` | 在局域网内自动发现盒子 |
| 二维码 | `birdbox://connect?host={host}&port={port}` | 扫码获取盒子连接地址，默认端口为 `8080` |

## 2. 设备接口

| 方法 | 接口 | 功能 | 关键数据 |
| --- | --- | --- | --- |
| GET | `/api/v1/device/status` | 连接握手、查询设备状态 | 设备信息、电池、温度、存储、存储卡、当前任务、软件版本 |
| POST | `/api/v1/device/pair` | 设备配对 | 当前仅定义路径，App 尚未实际调用 |
| POST | `/api/v1/jobs/{jobId}/actions` | 控制当前任务 | `action`: `pause`、`resume`、`cancel`、`retry` |

设备状态建议包含：

```json
{
  "device_id": "birdbox-01",
  "device_name": "拍鸟盒子",
  "api_version": "v1",
  "network_mode": "lan",
  "is_paired": true,
  "battery_percent": 82,
  "external_power": false,
  "temperature": 43.5,
  "storage_total": 1000000000000,
  "storage_free": 600000000000,
  "card_inserted": true,
  "card_readable": true,
  "current_job": null,
  "software_version": "1.0.0",
  "model_version": "1.0.0",
  "updated_at": "2026-07-24T10:00:00Z"
}
```

## 3. 拍摄项目接口

代码中的 `batchId` 对应盒子端的 `project_id`。

| 方法 | 接口 | 功能 | 关键参数 |
| --- | --- | --- | --- |
| GET | `/api/v1/projects` | 分页查询拍摄项目 | `page_size`、`state`、`sort`、`cursor` |
| GET | `/api/v1/projects/current` | 查询当前拍摄项目 | 无 |
| POST | `/api/v1/projects/{batchId}/resume` | 恢复指定拍摄项目 | 路径参数 `batchId` |

列表统一返回：

```json
{
  "items": [],
  "has_more": false,
  "next_cursor": null
}
```

## 4. 照片与分组接口

| 方法 | 接口 | 功能 | 关键参数 |
| --- | --- | --- | --- |
| GET | `/api/v1/projects/{batchId}/files` | 查询照片列表 | 分页、排序、鸟种、评分、标签、保留状态等 |
| POST | `/api/v1/projects/{batchId}/files/actions` | 批量处理照片 | `file_ids`、`operation`、`value` |
| GET | `/api/v1/projects/{batchId}/scenes` | 查询场景列表 | 路径参数 `batchId` |
| GET | `/api/v1/projects/{batchId}/groups` | 查询连拍或场景分组 | 可选 `scene_id` |
| GET | `/api/v1/species` | 搜索鸟种 | `search`、`page_size` |

照片列表支持的主要筛选参数：

| 参数 | 说明 |
| --- | --- |
| `cursor`、`page_size` | 分页 |
| `sort` | `captured_at_desc`、`score_desc`、`confidence_desc`、`recommended_desc` |
| `species`、`search` | 鸟种和关键字 |
| `min_score`、`min_confidence` | 最低评分和识别置信度 |
| `tags` | 多个标签用逗号分隔 |
| `keep_state` | `pending`、`keep`、`discard`、`featured` |
| `analysis_state`、`clarity_state` | 分析和清晰度状态 |
| `recognition_state` | `recognized`、`needs_review`、`unknown` |
| `recommended_only` | 是否只查看推荐照片 |
| `group_id`、`scene_id` | 分组和场景筛选 |

批量操作示例：

```json
{
  "file_ids": ["photo-01", "photo-02"],
  "operation": "keep",
  "value": null
}
```

`operation` 支持：

- `pending`：恢复待确认
- `keep`：保留
- `discard`：弃用
- `featured`：设为精选
- `add_tags`：添加标签，标签放在 `value`
- `remove_tags`：删除标签，标签放在 `value`

## 5. 照片详情与审阅接口

| 方法 | 接口 | 功能 | 关键数据 |
| --- | --- | --- | --- |
| GET | `/api/v1/files/{fileId}` | 查询照片详情 | 图片、识别结果、评分、主体框、标签、EXIF、人工决定 |
| GET | `/api/v1/files/{fileId}/history` | 查询修改历史 | 版本、来源、更新时间、摘要 |
| POST | `/api/v1/files/{fileId}/decision` | 保存人工审阅结果 | 保留状态、评分、鸟种、标签、版本 |

保存审阅结果示例：

```json
{
  "file_id": "photo-01",
  "keep_state": "keep",
  "user_score": 8.5,
  "user_species_id": "species-01",
  "user_species": "翠鸟",
  "user_tags": ["飞行", "清晰"],
  "updated_at": "2026-07-24T10:00:00Z",
  "version": 3
}
```

盒子端发现版本冲突时应返回 HTTP `409`。

## 6. 复制接口

| 方法 | 接口 | 功能 | 关键参数 |
| --- | --- | --- | --- |
| GET | `/api/v1/projects/{batchId}/copy/estimate` | 估算复制数量、容量及可用目标盘 | `mode` |
| POST | `/api/v1/projects/{batchId}/copy` | 创建复制任务 | `mode`、`target_id`、`xmp_enabled` |

复制模式：

| 模式 | 功能 |
| --- | --- |
| `keep` | 只复制保留照片 |
| `all` | 复制全部照片 |
| `dual` | 复制保留照片并创建完整备份 |

创建复制任务示例：

```json
{
  "mode": "keep",
  "target_id": "usb-01",
  "xmp_enabled": true
}
```

## 7. 任务与日志接口

| 方法 | 接口 | 功能 |
| --- | --- | --- |
| GET | `/api/v1/jobs` | 查询任务列表 |
| GET | `/api/v1/jobs/{jobId}` | 查询任务详情 |
| GET | `/api/v1/jobs/{jobId}/failures` | 查询任务失败文件 |
| POST | `/api/v1/jobs/{jobId}/actions` | 暂停、继续、取消或重试任务 |
| DELETE | `/api/v1/jobs/{jobId}` | 删除已完成、失败或取消的任务 |
| POST | `/api/v1/logs/export` | 生成诊断日志并返回 `download_url` |
| GET | `download_url` | 下载盒子生成的日志文件 |

任务类型：

- `import`：导入照片
- `analysis`：分析照片
- `copy`：复制照片
- `sync`：同步修改

任务状态：

- `idle`
- `running`
- `paused`
- `completed`
- `failed`
- `cancelled`

## 8. WebSocket 事件

连接地址：

```text
ws(s)://{box-host}/api/v1/events
```

消息格式：

```json
{
  "event_type": "job_progress",
  "payload": {},
  "timestamp": "2026-07-24T10:00:00Z"
}
```

支持的事件：

| 事件 | 功能 |
| --- | --- |
| `device_status_changed` | 设备状态变化 |
| `device_status` | 推送设备完整状态 |
| `status_changed` | 兼容设备状态变化事件 |
| `job_updated` | 任务信息更新 |
| `job_progress` | 任务进度更新 |
| `job_state_changed` | 任务状态变化 |

`payload` 应返回完整的设备或任务对象。当前 App 不会把增量字段与旧状态合并。

## 9. 通用协议约定

请求头：

```text
Accept: application/json
X-Client-Source: bird-companion-app
X-Api-Version: v1
Authorization: Bearer <token>
X-Idempotency-Key: <request-id>
```

- `Authorization` 仅在配置 Token 后发送。
- 所有 POST 请求都会携带 `X-Idempotency-Key`。
- 离线审阅操作重试时会复用原幂等键。

推荐成功响应：

```json
{
  "data": {
    "items": []
  }
}
```

也可以直接返回业务对象。若使用 `data`，其值应为 JSON 对象，列表请放在 `data.items` 中。

推荐错误响应：

```json
{
  "error_code": "VERSION_CONFLICT",
  "error_message": "数据已被更新"
}
```

## 10. 当前注意事项

1. `/api/v1/device/pair` 和 Token 鉴权尚未接入实际业务流程。
2. WebSocket 的 `payload` 需要返回完整对象，不能只返回变化字段。
3. `thumb_ref`、`preview_ref` 建议返回完整的 HTTP/HTTPS URL。
4. 日志下载目前不会自动携带 API 客户端的 Bearer Token。
5. 当前接口路径和请求头固定使用 API `v1`。
6. 离线重放只支持单张审阅和照片批量操作，不支持任务控制及创建复制任务。
