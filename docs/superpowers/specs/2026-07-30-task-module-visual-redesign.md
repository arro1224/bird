# 任务模块视觉重做规格

## 目标

以 `D:/birdphoto/任务` 下的 9 张设计稿作为唯一视觉基准，重做任务首页、SD 卡流程、复制流程、任务详情和任务结果。业务名称、状态和交互继续遵守两份项目需求文档，保留演示数据和现有后端适配边界。

## 已确认方向

- 采用“设计系统化还原”：先统一背景、页头、卡片、按钮、状态和间距，再逐页还原。
- 设计稿中的任务入口替换为需求规定的导入/索引、AI 分析、复制、同步。
- 不绘制假的 iOS 状态栏；Android 系统状态栏和导航条由系统管理。
- 水墨背景是每个任务页面的必要视觉层，不得移除或替换为纯色空白页。

## 页面范围

1. 任务首页。
2. SD 卡已检测、未检测、读取失败、无可处理照片。
3. 复制内容 2/3、复制确认 3/3。
4. 任务详情。
5. 任务结果。

当前代码中的“建立批次”表单页不再作为独立流程；检测到 SD 卡后直接创建导入任务并进入任务详情。“演示审阅”过渡页移出任务流程，分析完成后进入相册或当前批次审阅。

## 视觉系统

- 背景：暖纸纹理、低对比远山水面、边缘芦苇、少量飞鸟，正文区域保持足够留白。
- 主色：`#245E2B`；深色文字：`#14341E`；暖纸：`#F7F3EA`；卡片：`#FFFEFB`。
- 卡片：14-16dp 圆角，轻阴影，只用于独立信息容器，禁止卡片嵌套。
- 间距：24dp 页面边距，4/8dp 节奏，主要区块间距 16-24dp。
- 按钮：每屏一个主操作；主按钮森林绿填充，次按钮白底绿边，最小高度 52dp。
- 图标：同层级使用统一线性风格；成功、提醒、失败分别使用绿、橙、红，并配合文字而非只依赖颜色。
- 动画：仅进度和状态切换使用 180-280ms 动画；暂停、失败、断线和完成时停止进度动画。

## 页面规则

### 任务首页

保留设计稿的大标题、当前任务主卡、四宫格入口和任务列表。当前任务突出百分比和进度条，列表按进行中、需处理、已完成筛选。断线提示位于标题和当前任务之间，不覆盖任务数据。

### SD 卡流程

四种状态共用页头和水墨场景。已检测状态使用 SD 卡主视觉和数据卡；未检测使用空卡轮廓与三步说明；读取失败使用明确失败标识与原因列表；无照片使用相机卡与盒子场景及检查清单。

### 复制流程

复制内容页保留三种范围、目标存储、容量进度、XMP 开关和两级操作。确认页只显示最终摘要、安全说明、耗时和校验开关，不重复可编辑控件。

### 任务详情

顶部主卡突出任务类型、状态、数量、百分比和剩余时间；中部为四阶段时间线；底部为来源、当前文件、速度和失败数。动作根据任务状态显示，取消必须二次确认。

### 任务结果

成功标识、结果标题、四项关键指标、待复核提醒和两个主路径按设计稿排列。部分成功、失败、取消和校验失败复用相同骨架，仅改变状态色、文案、指标和可用动作。

## 适配和验收

- 目标基准为 426x923 logical pixels，并验证 360x800、412x915 和横屏/大字号无溢出。
- 所有触控区域不小于 48dp。
- 页面应支持 SafeArea、Android 返回、TalkBack 标签和文本缩放。
- 通过 Widget 测试、静态分析、APK 构建和模拟器截图对比后才算完成。
